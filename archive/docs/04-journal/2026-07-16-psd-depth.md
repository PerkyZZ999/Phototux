# Journal: PSD depth slice (2026-07-16)

## What shipped

- `phototux_io` PSD v1 RGB8 import: Raw (0) and PackBits/RLE (1) composite decode; layer records with channel rasters when present; compatibility report for subset / effects / incomplete layers.
- Reject ZIP compression, non-RGB, non-8-bit, PSB/v2.
- Multi-layer open path: `PsdOpened` carries `layer_rasters`; UI `open_document` + per-layer GPU upload (flattened fallback when only composite exists).
- Subset export: `export_psd` / `export_psd_path` (Raw, one layer record per raster layer + planar composite); File → Export → `*.psd`.
- Unit tests: raw/RLE composite, ZIP reject, export↔import pixel/name smoke.

## Honesty / ADR-018

Compatibility report still discloses subset limits. No perfect Photoshop round-trip claim. Export CPU composite is explicit export-path only (not canvas present).

## Deferred

16-bit/HDR, CMYK/Lab, ICC, ZIP, PSB, masks/effects/smart objects/text fidelity.
