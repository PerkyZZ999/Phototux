# Announcements

Drafts for announcing PhotoTux somewhere public. Each file says where the post
goes, what the venue expects, and what to do after posting.

| File | Venue |
|---|---|
| [`arch-forums.md`](arch-forums.md) | [Arch Linux Forums ▸ Community Contributions](https://bbs.archlinux.org/viewforum.php?id=39) |

These are drafts, not published copy. Read one through before posting it —
version numbers, the pre-release warning and the "what would help most" list
all go stale, and a post that claims something the build does not do is worse
than no post.
