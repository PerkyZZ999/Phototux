# Screenshots

Captured from a real build in an isolated 1920×1200 Wayland session, scaled to
1600 px wide. `.webp` is what the README and the websites use; `workspace.png`
exists as well because AppStream metadata wants PNG or JPEG.

The image being edited in them is synthetic — a dusk landscape generated
procedurally for this purpose, not a photograph — so there is no third-party
licence attached to anything shown here.

| File | Shows |
|---|---|
| `workspace.webp` | The editing workspace: tool shelf, options bar, canvas, and the Properties / Navigator / Layers docks |
| `welcome.webp` | First launch, before a document exists |
| `new-document.webp` | File ▸ New, with the 720p / 1080p / 2K / 4K presets |
| `menu-layer.webp` | The Layer menu |
| `blend-modes.webp` | The layer blend-mode list, grouped by family |
| `filter-gallery.webp` | Filter ▸ Filter Gallery, previewing before commit |
| `command-palette.webp` | The command palette (`Ctrl+Shift+P`) |
| `preferences.webp` | Edit ▸ Preferences |
