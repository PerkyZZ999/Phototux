Tools are grouped on the shelf the way Photoshop groups them, with a rule
between bands. A tool with a small triangle in its corner shares a slot with
others: press and hold, or right-click, to get the flyout. <kbd>Shift</kbd>
with the slot's key cycles through them.

## Move

| Tool | Shortcut | What it does |
|---|---|---|
| **Move** | <kbd>V</kbd> | Drags the active layer. Its options bar carries the align and distribute buttons. |

## Selection

| Tool | Shortcut | What it does |
|---|---|---|
| **Rectangular Marquee** | <kbd>M</kbd> | Selects a rectangle. |
| **Elliptical Marquee** | <kbd>Shift</kbd> <kbd>M</kbd> | Selects an ellipse. |
| **Lasso** | <kbd>L</kbd> | Freehand selection; releasing closes the outline. |
| **Polygonal Lasso** | <kbd>Shift</kbd> <kbd>L</kbd> | Selects a polygon, one click per corner. |
| **Magic Wand** | <kbd>W</kbd> | Selects everything contiguous with the clicked pixel and within tolerance of its colour. |
| **Color Range** | <kbd>Shift</kbd> <kbd>W</kbd> | Selects everything within tolerance of the clicked colour, contiguous or not. |

## Measure

| Tool | Shortcut | What it does |
|---|---|---|
| **Crop** | <kbd>C</kbd> | Trims the document to a rectangle. |
| **Free Transform** | <kbd>Ctrl</kbd> <kbd>T</kbd> | Scales, rotates and moves the active layer, committed as one step. |
| **Eyedropper** | <kbd>I</kbd> | Picks a colour from the composite. |

## Paint

| Tool | Shortcut | What it does |
|---|---|---|
| **Brush** | <kbd>B</kbd> | Paints with the current colour, size, hardness and texture. |
| **Clone Stamp** | <kbd>S</kbd> | Paints with pixels sampled from elsewhere in the layer. |
| **Eraser** | <kbd>E</kbd> | Clears pixels to transparency. |
| **Gradient** | <kbd>Shift</kbd> <kbd>G</kbd> | Draws a gradient across the selection, or the layer. |
| **Paint Bucket** | <kbd>G</kbd> | Fills a contiguous region with the current colour. |

### Focus tools

| Tool | Shortcut | What it does |
|---|---|---|
| **Blur** | <kbd>R</kbd> | Softens where you paint. |
| **Sharpen** | <kbd>Shift</kbd> <kbd>R</kbd> | Increases local contrast where you paint. |
| **Smudge** | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>R</kbd> | Drags colour along the stroke. |

### Tone tools

| Tool | Shortcut | What it does |
|---|---|---|
| **Dodge** | <kbd>O</kbd> | Lightens where you paint. |
| **Burn** | <kbd>Shift</kbd> <kbd>O</kbd> | Darkens where you paint. |
| **Sponge** | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>O</kbd> | Saturates or desaturates where you paint. |

## Vector

| Tool | Shortcut | What it does |
|---|---|---|
| **Path Edit** | <kbd>A</kbd> | Moves, adds and deletes the anchors of a shape layer's path. |
| **Text** | <kbd>T</kbd> | Creates and edits a text layer. |
| **Shape** | <kbd>U</kbd> | Draws a shape layer from a preset. |

## Navigate

| Tool | Shortcut | What it does |
|---|---|---|
| **Hand** | <kbd>H</kbd> | Pans the view. Holding <kbd>Space</kbd> gives you this temporarily from any tool. |
| **Zoom** | <kbd>Z</kbd> | Zooms in; hold <kbd>Alt</kbd> to zoom out. |

## Tool options

The options bar under the toolbar changes with the active tool. It is the only
piece of chrome that moves as you work — everything else stays where you left
it.

Some examples:

- **Brush** — preset, size, hardness, texture.
- **Move** — align and distribute.
- **Text** — font and size.
- **Magic Wand** and **Color Range** — tolerance and the four combine modes.
- **Marquee** and **Lasso** — the four combine modes.

## Every tool is also an action

Each tool appears in the [command palette](/guides/workspace/#the-command-palette)
(<kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>P</kbd>) and each shortcut is
rebindable in [Preferences](/guides/workspace/#keyboard-shortcuts). The list
above is the default binding, not a fixed one.
